# Refactor plan: splitting `codec.ts` and `coder.ts`

Status: **steps 1–2 of N done.** Actually extracted:
`src/lib/container/crc32c.ts` (+ barrel `src/lib/container/index.ts`) and
`src/lib/planner/budget.ts` (+ barrel `src/lib/planner/index.ts`) — level tier,
`pruningLevel()` and the wall-clock deadline, the only planner state every stage and
every worker must share. `codec.ts` imports them through the barrels and re-exports the
public names, so no caller moved. Both extractions were verified byte-identical on the
26-file golden manifest, and `node tests/run.mjs` passes.
Everything else below is still a plan, not a claim about the current tree.

## Why the split is risky

`src/lib/codec.ts` (~5.4 kLOC) and `src/lib/coder.ts` (~3.2 kLOC) are dense and
share mutable tuning state (`cmV20Tuning`, `activeLevel`, `strictPriorsFlag`,
`checksumFlag`, `probeDepth`, `containerModel`). A mechanical split would be
byte-invisible or the container format would silently change. `src/lib/parallel-worker-code.ts`
is generated by `scripts/build-worker-code.mjs` from the same sources, so every
move also has to keep that bundle in sync (`npm run check:worker` enforces it).

## Target layout

```
src/lib/container/   format constants, varint, header read/write, checksum trailer
src/lib/planner/     analyze → plan → candidates → refine* → coalesce
src/lib/models/      CM model (contexts, mixer, APM, match), transforms, anchors
src/lib/runtime/     codec entry points, worker pool, budgets, progress
```

## Guard for every step

1. `node tests/run.mjs` EXIT 0 (includes `tests/p12.test.ts` historical fixtures and the
   frozen containers in `tests/p121-fixtures.json`).
2. The 26-file golden manifest must be **byte-identical** in the default `max` profile.
3. `node scripts/build-worker-code.mjs && npm run check:worker` (the worker bundle must be
   rebuilt and must stay ≤ 512 KiB).
4. `UCZ_THREADS=1` and `UCZ_THREADS=4` must produce identical containers for the same input.

## Order (each step is its own commit)

| Step | Move | Notes |
|---|---|---|
| 1 ✅ | `crc32c.ts` + the v24 trailer | pure, no shared state |
| 2 ✅ | `planner/budget.ts` (level tier, pruning, deadline) | leaf module; workers inherit via `JobPayload.level` |
| 2 | varint + header parse/write (`getVar`, `planHeader`, `decompress` header prologue) | header bytes must not change |
| 3 ✅ | `container/format.ts`: `ID` enum, all flag bits, `MAX_CONTAINER_VERSION`, `containerHas*` predicates | leaf module; `codec.ts`/`coder.ts` re-export, callers unchanged |
| 4 | `analyze`/`detectRecordStride`/`detectLag*` | already isolated in `analyze.ts`; fold in |
| 5 | planner stages (`candidatesFor`, `refine*`, `coalesce`) | keep `probeDepth` semantics |
| 6 | CM model core (contexts, mixer, APM) | largest step; split in two |
| 7 | transforms / anchors | must keep byte order identical |
| 8 | runtime entry points + `parallel-*` | last, because the worker bundle depends on it |

Every step is "move code, change nothing else". If a step cannot pass guard 2, it is
reverted instead of adjusted — the format is the invariant, not the file layout.
